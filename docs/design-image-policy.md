# Politica de imagens do projeto

Este projeto pode usar imagens geradas para banners, paginas institucionais,
estados vazios e apoio visual de servicos. Essas imagens nao devem representar
um veiculo especifico anunciado no catalogo.

## Regras para imagens geradas

- Nao usar logos, emblemas, nomes de marcas ou identidade visual de terceiros.
- Nao imitar modelos reais reconheciveis, como esportivos ou SUVs de marcas famosas.
- Nao exibir placas legiveis.
- Nao exibir pessoas identificaveis.
- Nao copiar fachada, loja, uniforme ou sinalizacao de uma concessionaria real.
- Nao inserir texto dentro da imagem.
- Usar veiculos ficticios por categoria: coupe premium, sedan esportivo, SUV, hatch, pickup.
- Manter area de respiro para textos e CTAs quando a imagem for usada como banner.

## Uso permitido

- Hero da home.
- Banner do catalogo.
- Banner de financiamento.
- Banner de venda do carro.
- Paginas institucionais, contato, FAQ e estados vazios.

## Uso nao permitido

- Foto principal de um carro real anunciado.
- Galeria de detalhes de um veiculo especifico.
- Comparacao visual que induza o usuario a acreditar que o carro gerado e o item vendido.

Fotos de veiculos do catalogo devem vir do cadastro do produto ou de uma fonte
licenciada para aquele anuncio.
